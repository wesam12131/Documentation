= InputIDs list and their functionality

List of all the inputIDs and their functionality

[NOTE]
====
InputIDs are numerical Identifers for keybinds linked to GameplayAbilities

BASE ability: Base class ability for a group of abilities that share a somewhat similar functionality amongst themselves


====

[WARNING]
====
Some Gameplay Abilities seek a release before execution so you'd have to call both PressInputID then ReleaseInputID (Ex: GA_Phone)

Some other gameply abilities execute once with PressInputID

Some Gameplay Abilities consider PressInputID + ReleaseInputID as a *Hold* action, and a PressInputID only  as a *Press* action (Ex: GA_Interact)

Some Gameplay Abilities  may require  other certain abilities/actions to be already being performed prior (EX: GA_Slide requiring sprinting beforehand)

In the case of multiple **potential** abilities per input/per base ability, Utilize the BASE ability and ensure it belongs to the pawn (Get outer of Ability --> Compare PawnPrivate == Pawn)
====
