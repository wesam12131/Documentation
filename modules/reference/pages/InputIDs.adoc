= InputIDs list and their functionality

List of all the inputIDs and their functionality

[NOTE]
====
InputIDs are numerical Identifers for keybinds linked to GameplayAbilities

Invoking AbilitySystem's PressInputID means it will hold it forever until 

BASE ability: Base ability for a group of gameplay abilities

Input + release = press

====

[WARNING]
====
Certain actions may "Consume" the input and no ReleaseInputID would be required, while some actions do not.



Invoking AbilitySystem's PressInputID means it will hold it forever until  ReleaseInputID is called unless the GA consumes the input

PressInputID  on an InputID = Hold 

PressInputID + ReleaseInputID on the same InputID = press

Certain activations may require  other certain actions to be already being performed prior

In the case of multiple **potential** abilities per input/per base ability: Get all of the objects containing the BASE ability for said GA and compare the object's outer.PawnPrivate to the Player's pawn for ownership verification
====
